# Elementor Section Map

Use this map to rebuild the static website inside Elementor.

## Global

| Element | Elementor widget/container | CSS class |
|---|---|---|
| Page wrapper | Optional outer Container | `lh-page` |
| Standard section | Container | `lh-section` |
| Tight section | Container | `lh-section-tight` |
| Inner max-width container | Container boxed width | `lh-container` |
| Eyebrow label | Heading/Text | `lh-eyebrow` |
| Section head grid | Container | `lh-section-head` |
| Section kicker | Heading/Text | `lh-section-kicker` |
| Section title | Heading | `lh-section-title` |
| Section copy | Text Editor | `lh-section-copy` |
| Button | Button widget | `lh-button` |
| Primary button | Button widget | `lh-button lh-button-primary` |

## Header

| Element | Elementor widget/container | CSS class |
|---|---|---|
| Header container | Container, sticky optional | `lh-header` |
| Nav inner | Container horizontal | `lh-container lh-nav` |
| Logo/brand | Heading or Icon Box | `lh-brand` |
| Logo mark | Text/Icon | `lh-brand-mark` |
| Menu | Nav Menu widget | `lh-menu` |
| Header CTA | Button | `lh-nav-cta` |
